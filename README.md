# Intro to Superior Java Week 1 Challenge

# Instructions to Run File

## Terminal
1. Download
2. Navigate to the folder containing the  (for example: cd ~/Downloads/cc-4-0-java-bank-teller-challenge-venzah-git-main/Java-Intro/src)
3. Run: javac myMain.java
4. Run: java myMain

## IntelliJ
1. Download
2. Open IntelliJ
3. Select File > Open... > the newly downloaded folder 
4. In the lefthand navigation panel, expand the Java-Intro and src folder to reveal the Java files
5. Select the file labeled myMain
6. Select Run > Run... > myMain file
